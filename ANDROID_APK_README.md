# Ponto Progredir — APK Android

O APK usa Capacitor como invólucro Android e abre o portal publicado em `https://ponto.marinsdistemas.xyz/app?native=1`. O backend continua sendo o mesmo do PWA, portanto autenticação, marcações, fotos, localização, sincronização offline, auditoria e histórico permanecem centralizados no sistema atual.

## APK gerado

Arquivo: `releases/ponto-progredir-1.0.1-debug.apk`

Aplicativo: `Ponto Progredir`

Package ID: `com.marinsdigital.pontoprogredir`

## Permissões incluídas

O APK declara internet, câmera, localização aproximada/precisa e notificações, necessárias para os recursos já existentes do portal.

## Observação de distribuição

O arquivo gerado é um APK debug instalável para validação interna. Para publicação na Play Store ou atualização controlada em aparelhos já instalados, é necessário gerar uma versão release assinada com a chave oficial da organização. A chave não foi criada nem incluída no repositório.
